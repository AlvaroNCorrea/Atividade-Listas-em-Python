# 🚀 Lógica de Programação com Python

Este repositório contém uma coleção de exercícios práticos e desafios desenvolvidos em Python. O objetivo principal deste projeto é consolidar conceitos fundamentais da linguagem, cobrindo desde a manipulação de variáveis básicas até estruturas condicionais, listas, loops e desafios lógicos.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Google Colab** (Ambiente de desenvolvimento interativo)

## 📋 Recursos e Funcionalidades Desenvolvidas

Aqui está um resumo de tudo o que foi construído e explorado neste projeto:

1. **Entrada e Saída de Dados:**
   - Cadastro de perfil básico (nome, idade, altura e telefone).
   - Calculadora simples para somar preços de peças de roupas.

2. **Operadores Matemáticos & Expressões:**
   - Operações básicas: soma, subtração, multiplicação e divisão.
   - Operadores avançados: resto da divisão (`%`), potência (`**`) e cálculo de raiz com base e índice personalizados.

3. **Estruturas Condicionais e Tomada de Decisão:**
   - Validador simples de maioridade.
   - Jogo **Par ou Ímpar** interativo.
   - Jogo **Jokenpô (Pedra, Papel ou Tesoura)** completo com lógica de condições encadeadas.

4. **Listas e Estruturas de Repetição (`for` & `zip`):**
   - Percorrendo listas de forma simples.
   - Uso da função `zip()` para interagir e exibir dados combinados de duas listas de tamanhos iguais simultaneamente (como produtos e preços).
   - **Sacolão da Generation:** Sistema interativo que exibe o catálogo, permite cadastrar novos produtos dinamicamente (`.append()`) e remover itens do estoque (`.pop()`).

5. **Desafio Clássico:**
   - **FizzBuzz:** Algoritmo que conta de 1 a 100 aplicando regras condicionais de divisibilidade por 3, por 5, ou por ambos simultaneamente.
